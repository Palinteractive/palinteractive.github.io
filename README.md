# Patrick Aguilar Liriano — Portfolio Website

Static portfolio website prepared for GitHub Pages. No build system is required.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository. A good name is `patrickaguilar.github.io` if you want the root address `https://patrickaguilar.github.io/`.
2. Upload **all files and folders in this directory** to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait a minute or two for GitHub to publish the site.

If the repository uses another name, the URL will usually be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`. The site uses relative links so either setup works.

## Structure

- `index.html` — home / selected work
- `projects/` — project detail pages
- `assets/images/` — optimized WebP portfolio imagery
- `assets/videos/` — web-compressed MP4 clips
- `assets/docs/` — resume + PDF portfolio
- `css/styles.css` — visual system based on the original P.A_L portfolio
- `js/site.js` — small interaction / video bandwidth helpers

## Updating the site

Replace images while keeping the same filenames, or edit the HTML project pages directly. Video files were compressed for web delivery so they remain practical for GitHub hosting.
